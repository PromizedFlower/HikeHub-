## 一、第一層：自動驗針（6 支，約 10 秒）

### 1. 一次全跑（推薦）

把整段貼進 PowerShell 回車：

```powershell
$env:PYTHONIOENCODING='utf-8'
python tests/test_01_pyside_window.py --headless-check
python tests/test_02_supabase_auth.py
python tests/test_03_db_crud.py
python tests/test_04_storage_upload.py
python tests/test_05_osm_map.py --headless-check
python tests/test_06_location_source.py
```

第一次建議**一支一支跑**，方便看清每步輸出。

### 3. 三個「不是錯誤」的正常現象

1. **`test_03` 的點讚數字每次不一樣**：它是「切換」操作，重複跑會在
   `is_liked: True / like_count: 4` 與 `is_liked: False / like_count: 3` 之間來回，兩者都算 PASS。
2. **中文暱稱在 PowerShell 可能顯示亂碼**：終端編碼問題，只要看到 `[PASS]` 即無礙；QML 介面顯示正常。
   〔解法：設 `$env:PYTHONIOENCODING='utf-8'`〕
3. **`test_04` 會在 `user_uploads/` 產生測試圖**：已被 `.gitignore` 排除，不污染倉庫，可不管。

**真正的失敗**：出現紅色 `Traceback`、`AssertionError`、`ModuleNotFoundError`。請複製整段錯誤回報。

驗證「雲端資料本身對不對」，使用 `tests/verify_db.sql`。

1. 瀏覽器開 [supabase.com](https://supabase.com) → 確認是 `khqleyfszhsnavtdtwgn` 專案 → 左側 **SQL Editor** → **+ New query**。
2. 開啟本機 `tests/verify_db.sql`，`Ctrl+A` → `Ctrl+C`，貼進編輯框。
3. 按 `Ctrl+Enter`（或點綠色 **Run**）。

| 段落 | 正確結果 |
|---|---|
| 1. 各表行數 | profiles 6 / trails 10 / trail_segments 25 / checkpoints 22 / posts 6 / post_photos 5 / comments 6 / likes 12 / favorites 8 |

## 三、第三層：介面手動驗收（評分最看重）

啟動應用，**兩種方式任選其一**：

- **方式 A（推薦，最簡單）**：在檔案總管開啟專案根目錄
  `d:\codebuddy_rooms\fresh_fridge_development\hikehub\hikehub`，
  **直接雙擊 `启动Demo.bat`**。會開一個黑色小視窗跑啟動訊息，接著彈出 App 主視窗。
  （黑色視窗可最小化，關掉 App 後它會自動關閉；若啟動失敗，它會停住並顯示錯誤原因。）
  > 請雙擊 `.bat`，**不要**雙擊 `main.py`——後者只會用編輯器打開或一閃而過。
- **方式 B（命令列）**：

```powershell
python main.py
```

彈出 390×844 手機視口，底部 5 個 Tab（首頁 / 線路 / 出發 / 社區 / 我的）。

### 步驟 1｜確認連上雲端
登入頁**頂部綠色提示條**必須顯示：

```
✓ Supabase 環境已就緒：Supabase Cloud (已連線)
```

> 若顯示「本地鏡像同步模式」或「⚠️ 檢查 .env 配置」→ 先別繼續，檢查 `.env` 或回報提示文字。

### 步驟 2｜測登入（含錯誤密碼）
- 下方「預建 6 個測試帳號」列表**點一下「阿瀚 · 山野行者」**，帳密自動填入 → 點登入 → 進入首頁。
- 驗錯誤提示：登出後把密碼改成 `wrong123` 再登入 → 應出現紅字
  「密碼錯誤，預建測試帳號密碼統一為 HikeHub2026!」

### 步驟 3｜首頁 / 線路（讀資料）
- 首頁應見 10 條香港路線（龍脊、麥理浩徑二段、獅子山…）。
- 「線路」Tab 試**區域 / 難度篩選**；點進任一條詳情 → 應見「路段」列表、補給點、撤退點標記。
- 資料來自雲端 `trails` / `trail_segments` / `checkpoints`。

### 步驟 4｜出發（地圖與定位）
- 「出發」Tab → 應見 OSM 地圖、路線軌跡折線。
- 座標顯示演示模式 `22.228367, 114.242633`（教室無 GPS 時的模擬定位，屬正常）。
- 可試打卡點互動。

### 步驟 5｜社區（寫操作）
- 「社區」Tab → 應見動態 / 問答 / 行山記錄三類貼文。
- 點開一條貼文 → **點讚**（數字 +1）、**收藏**、**寫一則評論**。
- 問答貼可見「已採納」標記（`trail-02` 交通提問下，輝哥的回答）。

### 步驟 6｜驗證「真的持久化」（關鍵）
區分前端假資料與真實落庫的關鍵動作：

1. 記住剛點的讚 / 發的評論。
2. **關掉應用視窗**，重新執行 `python main.py`。
3. **換另一個帳號登入**（例如 `kaki@hikehub.hk`，密碼同為 `HikeHub2026!`）。
4. 回到同一條貼文 → 讚數、評論仍在。

資料仍在即證明寫進雲端 Postgres，而非僅介面暫存。

### 步驟 7｜我的
「我的」Tab → 改暱稱或簡介 → 存檔 → 重開應用仍在。

## 六、故障排查

| 現象 | 先試這個 |
|---|---|
| `ModuleNotFoundError: No module named 'PySide6'` | `pip install -r requirements.txt` |
| 登入頁顯示「未配置 .env」 | 確認 `.env` 在專案根目錄，且 `cd` 到 `hikehub\hikehub` |
| `AssertionError: Login failed` | 跑 `tests/test_02_supabase_auth.py` 看 `Status Summary`；`remote_online` 應為 `True` |
| 地圖空白 | 教室網路可能擋 OSM 瓦片，屬外部環境；驗針 PASS 即代表地圖元件正常 |
| 任何紅色報錯 | 整段複製回報，附上執行的命令 |
