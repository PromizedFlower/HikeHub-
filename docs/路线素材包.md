# 行山腳 HikeHub · 路線開源素材包

> 用途：演示「發布動態」時，從本機選擇圖片並上傳的素材庫。
> 圖片來源：Unsplash（開源圖庫，可商用、免授權）；學生作業專案，無版權負擔。
> 本地目錄：`assets/route-photos/<路線>/01.jpg …`，共 10 條路線 × 3 張。

## 使用方法（演示發布）
1. 開啟 App → 登入 → 底部「社區」→ 右上「＋」發布動態。
2. 切到「發動態（相片分享）」，點「＋ 從本機添加相片」。
3. 在檔案總管開啟 `assets/route-photos/` 選擇對應路線的圖片（可一次選多張）。
4. 填寫標題與內文 → 關聯路線 → 點「確認發布到社區」，圖片會自動上傳至雲端 Storage。
